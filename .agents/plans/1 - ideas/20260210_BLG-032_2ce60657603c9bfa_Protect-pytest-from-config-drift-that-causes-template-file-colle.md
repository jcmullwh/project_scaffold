## Title

Protect pytest from config drift that causes template file collection errors

## Problem

When pytest config is altered, test discovery can scan template files and fail with syntax errors from non-runnable templated code.

## User impact

Minor config mistakes produce confusing failures unrelated to actual tests.

## Proposed fix

Add a guard that enforces expected pytest `testpaths` configuration and fails with a targeted message when misconfigured.

## Investigation steps

- Codify expected pytest settings (including `testpaths = ["tests"]`).
- Add CI check that asserts required pytest config keys are present.
- Verify failure messaging points to config remediation rather than raw syntax collection output.

## Success criteria

- CI fails early when pytest configuration section is missing or altered incorrectly.
- Pytest no longer scans templated source trees during normal runs.
