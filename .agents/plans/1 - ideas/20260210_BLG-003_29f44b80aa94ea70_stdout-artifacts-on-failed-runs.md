## Title

Capture actionable stderr/stdout artifacts on failed runs

## Problem

## User impact

Triage is slowed because failure context is missing even when severity is high.

## Proposed fix

Ensure adapters always emit diagnostic artifacts on failure (stderr/stdout snippets, provider error object, and truncation marker if limits apply).

- Add fallback capture from in-memory error payload when process streams are empty.
- Add unit tests for empty-stream failure scenarios.
