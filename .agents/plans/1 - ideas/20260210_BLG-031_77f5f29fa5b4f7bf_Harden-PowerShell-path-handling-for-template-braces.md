## Title

Harden PowerShell path handling for template braces

## Problem

PowerShell commands are fragile with literal template braces; `-LiteralPath` was required to avoid command rejection/failure.

## User impact

Windows users can hit pre-execution command failures when accessing template paths.

## Proposed fix

Standardize Windows command generation to use literal path handling and safe quoting for brace-containing template paths.
