## Title

Stabilize deptry exclusions for `.agents/dropins` and prevent TOML escape regressions

## Problem

`pdm run deptry .` is analyzing `.agents/dropins` template code that should be excluded, and exclusion updates are fragile due to TOML backslash escaping mistakes.

## User impact

Contributors and CI see false dependency failures unrelated to product code, creating confusion and wasted debugging time during onboarding and routine checks.

## Proposed fix

Update `tool.deptry.extend_exclude` to reliably exclude `.agents/dropins` template paths, normalize regex patterns to reduce escape complexity, and add an automated parse/deptry regression check to catch TOML escaping errors.
