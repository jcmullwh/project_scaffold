## Title

Exclude `.agents/dropins` (or `.agents/`) from deptry to prevent false positives

## Problem

`deptry` scans drop-in/template code under `.agents/dropins` and reports dependency issues that are not actionable in the host repo context, causing `pdm run deptry .` to fail or appear broken.

## User impact

Blocks CI/dev workflow when deptry is a gate and creates first-run validation noise that slows onboarding and adoption.

## Proposed fix

Update `pyproject.toml` deptry configuration to exclude drop-in/template code (prefer a narrow pattern like `.agents[\\/]dropins[\\/]`, or exclude all of `.agents[\\\\/]` if appropriate) and document why that path is excluded.
