## Title

Add documented fallback when PDM hangs on Windows (pip/global-python path to first success)

## Problem

Some Windows environments observe `pdm install` hanging indefinitely; users can still run tests via global Python in some cases, but this workaround is not front-and-center.

## User impact

Users get stuck at the very first setup step and abandon; especially painful for onboarding.

## Proposed fix

In `README.md`/`CONTRIBUTING.md`, add a “If `pdm install` hangs on Windows” section with a short workaround (e.g., create venv explicitly / run `pdm info` first) and a minimal fallback to run `python -m pytest ...` when dependencies are already available.
